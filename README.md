# এমপিও শিক্ষক বেতন ক্যালকুলেটর

এমপিওভুক্ত শিক্ষক-কর্মচারীদের জাতীয় বেতন স্কেল ২০২৬ অনুযায়ী মূল বেতন, ভাতাসহ বেতন ও বকেয়ার আনুমানিক হিসাব।

- লাইভ সাইট: https://mpo-calculator.vercel.app
- ভিডিও টিউটোরিয়াল: https://mpo-calculator.vercel.app/mpo-guide.mp4

## ফাইল

| ফাইল | কী আছে |
|---|---|
| `index.html` | ক্যালকুলেটর (একক ফাইল, কোনো বিল্ড লাগে না) |
| `mpo-guide.mp4` | বাংলা ধারাভাষ্যসহ ভিডিও টিউটোরিয়াল (৩ মিনিট) |
| `mpo-guide.vtt` | ভিডিওর বাংলা সাবটাইটেল |
| `docs/user-guide.pdf` | ব্যবহারের ধাপ, হিসাবের সূত্র, উদাহরণ ও প্রশ্নোত্তর |
| `docs/sample-report.pdf` | প্রিন্ট / পিডিএফ রিপোর্টের নমুনা |
| `docs/guide.html` | নির্দেশিকার মূল ফাইল |

## চালানো ও হালনাগাদ

- সব ফাইল একই ফোল্ডারে রেখে যেকোনো ওয়েব হোস্টিংয়ে আপলোড করলেই চলে।
- এই repo Vercel-এর সঙ্গে যুক্ত: `main` ব্রাঞ্চে push করলে সাইট নিজে থেকে হালনাগাদ হয়।

এটি একটি আনুমানিক হিসাব; প্রকৃত বেতনের সঙ্গে হুবহু না-ও মিলতে পারে।
